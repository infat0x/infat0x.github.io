# Haqqımda

Veb, şəbəkə və infrastruktur təhlükəsizliyi, zəifliklərin aşkarlanması, red team əməliyyatları və offensive alətlərin inkişafı üzrə ixtisaslaşmış **Penetration Tester**. Go əsaslı JS kəşfiyyat mühərriki, AI dəstəkli Fayl Bütövlüyü Monitorinqi (FIM) sistemi və Swagger API kəşfiyyat alətləri kimi istehsalat səviyyəli həllər hazırlamışam. CompTIA PenTest+, CRTA, RHCSA və IBM Cyber Threat Management sertifikatlarına sahibəm. Hal-hazırda Bakı Dövlət Universitetində Kompüter Elmləri üzrə təhsilimi tamamlayıram.

## İş Təcrübəsi

### Penetration Tester Intern &mdash; Bir Ecosystem
*Fevral 2026 &ndash; Avqust 2026*

* Daxili və müştəri yönümlü bank sistemlərinə qarşı veb tətbiq nüfuzetmə testləri həyata keçirmiş, SQLi, reflected/stored XSS, IDOR, SSRF, BOLA və JWT konfiqurasiya zəifliklərini istismar etmişəm.
* Burp Suite vasitəsilə manual API təhlükəsizlik qiymətləndirmələri aparmış, etibarsız birbaşa obyekt müraciətlərini (IDOR), çatışmayan rate-limiting və həssas məlumat sızmalarını aşkar etmişəm.
* Gizli parametrləri və biznes məntiqi xətalarını müəyyən etmək üçün client-side skriptləri reverse-engineer etmişəm.
* Fərdi və maliyyə məlumatlarının icazəsiz sızmasının qarşısını alan DLP memarlığı və siyasət icra mexanizmləri ilə tanışam.
* Çoxmərhələli hücum modellərini müəyyən etmək üçün XDR telemetriya axınlarını və korrelyasiya olunmuş şəbəkə/endpoint siqnallarını analiz etmişəm.
