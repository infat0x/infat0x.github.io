# Caido Automate Payload Extractor (CAPE): Bridging the Proxy Intruder Gap

*Published: October 2026 | Tags: Caido, Web Security, Bug Bounty, Tooling, Pentest*

## The Workflow Gap

During modern web application assessments and bug bounty hunting, workflow speed is critical. Migrating daily testing from legacy proxies to [Caido](https://caido.io) has been a massive upgrade in memory efficiency and raw performance. However, one specific routine from Burp Suite Intruder was sorely missed: the ability to quickly right-click or single-click to extract and export filtered payloads directly from an attack run.

When running fuzzing or parameter brute-force sessions in Caido Automate, isolating successful payloads (such as HTTP 200 OK responses or reflected tokens) and immediately pivoting them into fresh wordlists for tools like `ffuf` or `gobuster` required cumbersome workarounds.

To solve this, I designed and built **Caido Automate Payload Extractor (CAPE)** — a native, high-density plugin that integrates directly into Caido's core to inspect, filter, and extract Automate payloads in real time.

![CAPE running inside Caido with PortSwigger Web Security Academy](assets/img/cape-action.png)

## Core Capabilities

CAPE was built to feel like an organic, first-party part of Caido, matching its dark graphite aesthetic and interaction patterns.

### 1. High-Density Attack Run Extraction
The plugin reads attack sessions generated by Caido Automate via QuickJS RPC. It loads all executed requests and extracts the injected payload list along with request and response metrics.

### 2. Side-by-Side Raw Inspector
Replicating Caido's native master-detail layout, CAPE features split-pane Request and Response viewers:
* **Request Pane:** Shows the real raw HTTP stream with line numbers and dynamic payload reflection highlighting so you can instantly see where your input landed.
* **Response Pane:** Displays formatted status codes, headers, and syntax-highlighted bodies, with toggle controls for Pretty and Raw views.

### 3. Rapid Filtering & Deduplication
* **Color-Coded Status Filter:** Dropdown menu allowing one-click filtering by `All`, `200 OK`, `2XX`, `3XX`, `4XX`, and `5XX`.
* **Instant Search:** Full-text filtering across payloads, requests, response bodies, sequence IDs, and response lengths.
* **Automatic Deduplication:** A single toggle to prune redundant entries before export.

### 4. Fast Wordlist Export
* **Copy Payloads:** Copies filtered payloads as clean newline-separated wordlists straight to the system clipboard.
* **Export .txt:** Downloads the wordlist as a `.txt` file ready for external fuzzing pipelines.
* **Double-Click Row:** Double-clicking any table entry copies that specific payload immediately.
* **Global Shortcut (`Ctrl + Shift + C`):** A system-wide shortcut within Caido to immediately copy all 200 OK payloads from the latest attack session without even switching tabs.

## Technical Architecture

Under the hood, CAPE connects the frontend UI to Caido Core through a typed RPC bridge:

```
+-------------------------------------------------------------+
|                     Caido UI (Frontend)                     |
|  - High-density table with dynamic resizers & zebra rows    |
|  - Side-by-side Request/Response code viewers               |
|  - Color-coded status filter and export controls            |
+------------------------------+------------------------------+
                               | Typed RPC (sdk.backend)
+------------------------------v------------------------------+
|                   QuickJS Runtime (Backend)                 |
|  - Exposes getRuns and getRunPayloads RPC methods           |
|  - Queries Caido Core GraphQL API (requestsByOffset)        |
|  - Decodes RFC 4648 Base64 payloads and raw HTTP streams    |
+------------------------------+------------------------------+
                               | GraphQL
+------------------------------v------------------------------+
|                      Caido Core Engine                      |
|  - Project database, Automate runs, and request storage     |
+-------------------------------------------------------------+
```

1. **GraphQL Integration:** The backend leverages Caido's internal GraphQL endpoint (`automateEntry` -> `requestsByOffset`) with automatic pagination (fetching up to 5,000 items per batch) to retrieve large attack runs without UI freezing.
2. **Payload Decoding:** Raw payload buffers and HTTP streams are decoded from base64 safely, handling binary edge cases and multibyte UTF-8 characters.
3. **Zero Dependencies:** The plugin operates purely within Caido's embedded runtime environment, requiring no external processes or daemons.

## Published in the Caido Community Store

CAPE is now officially accepted and live in the [Caido Community Store](https://www.caido.io/plugins/).

![Automate Payload Extractor listed in the Caido Community Store](assets/img/cape-store.png)

### Installation

* **Method 1 (In-App Store):** Open Caido, navigate to **Plugins -> Store**, search for `Automate Payload Extractor`, and click **Install**.
* **Method 2 (Manual Zip):** Download the latest `plugin_package.zip` from the [GitHub Releases](https://github.com/infat0x/cape/releases) page and drag it directly into the Caido window.
